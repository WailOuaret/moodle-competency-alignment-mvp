Computers exchange data over networks using agreed rules called protocols. The Internet protocol moves packets between machines, while TCP makes sure that the packets arrive complete and in order. A web browser then uses HTTP on top of them to ask a server for a page, and DNS translates a name such as example.org into the address of that server.

Cloud providers rent computing resources over the network. Instead of buying a server, an organisation starts a virtual machine or a container in minutes and pays for the time it runs. Edge and fog computing move part of the work closer to sensors and devices, which reduces delay and the amount of data sent over long distances. Internet of Things devices rely on this model.

Every connected system is exposed to attack, so security is designed in from the start. Data is encrypted in transit with TLS and, when it is sensitive, at rest as well. Users prove who they are with strong passwords and a second factor, and each account receives only the permissions it needs. Firewalls limit which services can be reached, and software is updated promptly when a vulnerability is published.

Security is also a habit: teams log important events, review them and practise how they would respond to an incident.
